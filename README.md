# Telecommunications Database Design & SQL Analytics
---
## Project Overview

Designed and implemented a relational database for a telecommunications provider using MySQL. This project demonstrates database modelling, normalization, advanced SQL analytics, stored procedures, stored functions, query optimization, and distributed database concepts.
---
## Business Problem
Telecommunications companies manage large volumes of customer, subscription, billing, payment, call records, and support data. This project demonstrates how a normalized relational database can efficiently manage operational data while supporting business analytics and reporting.
